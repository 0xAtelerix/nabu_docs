# How to connect Binance to Nabu: a step-by-step guide

## Step 1: Start the connection in Nabu

1\. Go to [app.nabu.pro/settings](https://app.nabu.pro/settings).

2\. In the first tab, under Connect Exchange Account, select Binance.

<figure><img src="/assets/images/binance (1).png" alt="" width="624"><figcaption></figcaption></figure>

## Step 2: Create your API Key on Binance

3\. Head to [binance.com/en/my/settings/api-management](https://www.binance.com/en/my/settings/api-management) and click on **Create API** to create your API Key.

<figure><img src="/assets/images/binance (2).png" alt="" width="624"><figcaption></figcaption></figure>

4\. For futures & spot, make sure that the following fields are ticked: **Enable Futures** & **Enable Spot & Margin & Stock Trading**.

<figure><img src="/assets/images/binance (3).png" alt="" width="624"><figcaption></figcaption></figure>

Note: for Futures make sure that you have your account set up and available funds.

<figure><img src="/assets/images/binance (4).png" alt="" width="308"><figcaption></figcaption></figure>

5\. Tick the **Enable Symbol Whitelist** field and ensure to add assets that you would like to whitelist for trading purposes.

<figure><img src="/assets/images/binance (5).png" alt="" width="451"><figcaption></figcaption></figure>

6\. In the **IP access restrictions** field select **Restrict access to trusted IPs only (Recommended)** and use `2.58.64.162`.

<figure><img src="/assets/images/binance (6).png" alt="" width="624"><figcaption></figcaption></figure>

7\. Once completed, save the changes and head back to [app.nabu.pro](https://app.nabu.pro).

## Step 3: Nabu exchange settings

8\. Head back to the settings and enter your API Key and API Secret for Binance.

<figure><img src="/assets/images/binance (7).png" alt="" width="624"><figcaption></figcaption></figure>
