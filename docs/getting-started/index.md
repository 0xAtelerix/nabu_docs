# Getting started

Nabu trades through an exchange account that you own and fund. Linking a venue is the first step: until an account is connected, a strategy can be generated and backtested, but it cannot be deployed.

Pick the venue you want to trade on and follow its guide.

## Connect a venue

- [Connect Hyperliquid](how-to-connect-hyperliquid-to-nabu-a-step-by-step-guide.md): connect a wallet you already trade with, or create a new Nabu trading wallet, and approve Nabu to place orders for you.
- [Connect Binance](how-to-connect-binance-to-nabu-a-step-by-step-guide.md): create an API key with the right permissions, symbol whitelist, and IP restrictions, then link it in Nabu.

Both guides start the same way, on the **Exchanges** tab of your Nabu settings at [app.nabu.pro/?settings=exchanges](https://app.nabu.pro/?settings=exchanges).

## Before you start

- Keep your private keys and seed phrases to yourself. Nabu never asks for them: Hyperliquid is connected by approving Nabu in your wallet.
- Keep your API keys to yourself. Nabu asks for a Binance API key only on the **Exchanges** tab.
- Fund your Hyperliquid account with at least 5 USDC before you connect it.
- Restrict a Binance API key to the trusted IP addresses listed in its guide, and to the symbols you intend to trade.
- New to the terminology? The [glossary](../glossary.md) covers [CEX](../glossary.md#cex), [DEX](../glossary.md#dex), [PSL](../glossary.md#psl), and the rest.
